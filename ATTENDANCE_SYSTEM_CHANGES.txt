# Attendance System Changes - Summary

## Backend Changes Completed ✅

### 1. Updated Workday Model (models/Workday.js)
- Added `attendanceType` field: ENUM('full_day', 'half_day', 'leave')
- Added `standardHours` field: FLOAT (8 for full day, 4 for half day, 0 for leave)
- Kept clockIn/clockOut for backward compatibility (marked as deprecated)

### 2. Updated Workday Routes (routes/workday.js)
- Modified `/status` endpoint to return attendanceType and standardHours
- Added `/mark-attendance` POST endpoint for employees to select attendance type
  - Accepts: { attendanceType: 'full_day' | 'half_day' | 'leave' }
  - Auto-calculates standardHours based on type
  - Auto clock-in when marking attendance

### 3. Added Manager Activity Creation (routes/manager.js)
- Added POST `/api/manager/activities` endpoint
- Managers can create activities for employees in their department
- Required fields: title, assignedToId
- Optional fields: description, priority, status
- Validates employee is in manager's department

## API Endpoints

### New Endpoints:
- POST `/api/workday/mark-attendance` - Mark attendance type
  Request: { attendanceType: 'full_day' | 'half_day' | 'leave' }
  Response: { message, attendanceType, standardHours }

- POST `/api/manager/activities` - Create activity (Manager only)
  Request: { title, description, assignedToId, priority, status }
  Response: { message, activity }

### Modified Endpoints:
- GET `/api/workday/status` - Now returns:
  { attendanceType, standardHours, clockedIn, clockInTime, clockOutTime }

## Productivity Calculation Logic

### Old Logic (Clock-based):
```
totalMinutes = clockOut - clockIn
productivity = (timeSpentOnActivities / totalMinutes) * 100
```

### New Logic (Standard Hours-based):
```
standardMinutes = standardHours * 60
productivity = (timeSpentOnActivities / standardMinutes) * 100

Where:
- Full Day: standardHours = 8 (480 minutes)
- Half Day: standardHours = 4 (240 minutes)
- Leave: standardHours = 0 (0 minutes, productivity = 0%)
```
