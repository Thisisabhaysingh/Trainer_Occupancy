BRANCH-WISE CATEGORIZATION & TEAM LEAD IMPLEMENTATION
=====================================================

OVERVIEW:
---------
This implementation adds branch-wise categorization to the MIS system with Team Lead (TL) role support.
Each branch can have multiple departments, each department has one Team Lead, and managers are branch-specific.

KEY FEATURES:
-------------
1. Team Lead (TL) Role: New role between manager and employee
2. Branch-wise Organization: Departments are organized by branches
3. Separate TL Dashboard: Team leads have their own dashboard to manage their department
4. Branch-specific Managers: Managers only manage employees in their branch
5. Department-specific Team Leads: Each department has one team lead

DATABASE CHANGES:
-----------------

1. Users Table:
   - Added 'teamlead' to role ENUM
   - Added branchId column (INT, nullable)
   - Added foreign key constraint to Branches table

2. Departments Table:
   - Added branchId column (INT, nullable)
   - Added teamLeadId column (VARCHAR, nullable)
   - Added foreign key constraints for branchId and teamLeadId

3. Branches Table:
   - Already exists with managerId field
   - Manages branch-level operations

ROLE HIERARCHY:
---------------
Admin (Highest)
  └── Manager (Branch-level)
      └── Team Lead (Department-level)
          └── Employee (Lowest)

PERMISSIONS:
------------

Admin:
- Full system access
- Manage all branches, departments, and users
- View all analytics

Manager:
- Manage employees in their branch only
- View branch-level analytics
- Create employees and team leads in their branch

Team Lead:
- Manage employees in their department only
- View department-level analytics
- Assign activities to employees in their department
- Cannot create new users (only admin and manager can)

Employee:
- View and update their own activities
- Track their own time entries
- View their own performance

CREATING A TEAM LEAD USER:
---------------------------

Option 1: Via API (Admin/Manager):
POST /api/employees
{
  "employeeCode": "TL001",
  "name": "John Doe",
  "email": "john.doe@example.com",
  "password": "securepassword",
  "role": "teamlead",
  "departmentId": 1,
  "branchId": 1
}

Option 2: Direct Database Insert:
INSERT INTO users (employeeCode, name, email, password, role, departmentId, branchId, createdAt, updatedAt)
VALUES ('TL001', 'John Doe', 'john.doe@example.com', '$2a$10$hashedpassword', 'teamlead', 1, 1, NOW(), NOW());

Then assign to department:
UPDATE departments SET teamLeadId = 'TL001' WHERE id = 1;

ASSIGNING DEPARTMENTS TO BRANCHES:
-----------------------------------

UPDATE departments SET branchId = 1 WHERE name = 'Coding';
UPDATE departments SET branchId = 1 WHERE name = 'Mechatronics';
UPDATE departments SET branchId = 2 WHERE name = 'Electronics';

ASSIGNING MANAGERS TO BRANCHES:
--------------------------------

UPDATE users SET branchId = 1 WHERE employeeCode = 'MGR001' AND role = 'manager';
UPDATE Branches SET managerId = 'MGR001' WHERE id = 1;

TROUBLESHOOTING:
----------------

Issue: "Unknown column 'branchId'" error
Solution: Run the ALTER TABLE queries for users and departments tables

Issue: "Data truncated for column 'role'" error
Solution: Run the ALTER TABLE query to modify the role ENUM

Issue: Team lead cannot login
Solution: Verify the user has role='teamlead' and departmentId is set

Issue: Team lead dashboard shows no data
Solution: Ensure the department has activities and employees assigned

Issue: Foreign key constraint fails
Solution: Ensure referenced records exist in parent tables (Branches, users)

API ENDPOINTS SUMMARY:
----------------------

Authentication:
POST /api/auth/login - Login (all roles)
POST /api/auth/logout - Logout (all roles)
GET /api/auth/me - Get current user (all roles)

Team Lead Specific:
GET /api/teamlead/analytics - Get department analytics
GET /api/teamlead/employees - Get department employees
GET /api/teamlead/activities - Get department activities
POST /api/teamlead/activities/assign - Assign activity to employee

Employee Management:
GET /api/employees - Get all employees (admin, manager, teamlead)
POST /api/employees - Create employee/teamlead/manager (admin, manager, teamlead)
GET /api/employees/:id - Get employee details
PUT /api/employees/:id - Update employee
DELETE /api/employees/:id - Delete employee
