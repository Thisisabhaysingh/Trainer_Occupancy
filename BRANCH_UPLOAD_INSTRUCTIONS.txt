HOW TO USE

STEP 1: Prepare Your Excel File
--------------------------------
Make sure your Excel file has:
- Column A: Employee Number
- Column B: Name
- Column C: Email
- Column G: Department
- Column H: Location (Branch) ← NEW!

Example:
┌──────┬──────────┬──────────────────┬────────────┬──────────┐
│  A   │    B     │        C         │     G      │    H     │
├──────┼──────────┼──────────────────┼────────────┼──────────┤
│ EMP1 │ John Doe │ john@example.com │ Coding     │ Mumbai   │
│ EMP2 │ Jane Doe │ jane@example.com │ Electronics│ Delhi    │
│ TL01 │ Bob Lee  │ bob@example.com  │ Coding     │ Mumbai   │
└──────┴──────────┴──────────────────┴────────────┴──────────┘

STEP 2: Run the Upload Script
------------------------------
node upload_employees.js

The script will:
1. Read your Excel file
2. Create branches from Location column
3. Create or UPDATE employees
4. Assign branch to each employee
5. Show summary with created/updated counts

STEP 3: Verify Branch Assignments
----------------------------------
node verify_branches.js

This will show:
- List of all branches
- Employee count per branch
- Employees without branch
- Department-wise distribution

=====================================================
COLUMN MAPPING
=====================================================

The script uses these column indexes (0-based):

employeeNo: 0    → Column A (Employee Number)
name: 1          → Column B (Name)
email: 2         → Column C (Email)
department: 6    → Column G (Department)
location: 7      → Column H (Location/Branch) ← NEW!

If your Excel has different columns, edit upload_employees.js:

const COLUMN_MAPPING = {
  employeeNo: 0,
  name: 1,
  email: 2,
  department: 6,
  location: 7,  // Change this number if Location is in different column
};

DATABASE QUERIES TO VERIFY
=====================================================

After running the script, verify in database:

-- Check all branches
SELECT * FROM Branches;

-- Count employees per branch
SELECT 
  b.name as branch,
  COUNT(u.employeeCode) as employee_count
FROM Branches b
LEFT JOIN users u ON b.id = u.branchId
GROUP BY b.name;

-- List employees with their branch
SELECT 
  u.employeeCode,
  u.name,
  u.email,
  b.name as branch,
  d.name as department
FROM users u
LEFT JOIN Branches b ON u.branchId = b.id
LEFT JOIN departments d ON u.departmentId = d.id
ORDER BY b.name, u.name;

-- Find employees without branch
SELECT 
  employeeCode,
  name,
  email
FROM users
WHERE branchId IS NULL;

=====================================================
TROUBLESHOOTING
=====================================================

Error: "Cannot find module './models/Branch'"
---------------------------------------------
Solution: Make sure Branch model exists
Check: models/Branch.js should exist

Error: "Column 'branchId' doesn't exist"
----------------------------------------
Solution: Run database migrations first
See: DATABASE_MIGRATION_QUERIES.sql

No branches created
-------------------
Solution: Check if Location column (H) has values
The script only creates branches if location is not empty

Employees not updated
---------------------
Solution: Script looks for employeeCode, not email
Make sure employeeCode in Excel matches database

Wrong column data
-----------------
Solution: Check COLUMN_MAPPING in upload_employees.js
Adjust column indexes to match your Excel structure

UPDATING BRANCH ASSIGNMENTS
=====================================================

To update branch for specific employees:

Method 1: Update Excel and Re-run Script
-----------------------------------------
1. Update Location column in Excel
2. Run: node upload_employees.js
3. Script will update existing employees

Method 2: Direct SQL Update
----------------------------
-- Update single employee
UPDATE users 
SET branchId = 1 
WHERE employeeCode = 'EMP001';

-- Update multiple employees
UPDATE users 
SET branchId = 2 
WHERE employeeCode IN ('EMP002', 'EMP003');
