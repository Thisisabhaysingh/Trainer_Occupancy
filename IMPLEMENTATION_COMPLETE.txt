## API Endpoints

### New Endpoints:
- **POST** `/api/workday/mark-attendance`
  - Request: `{ attendanceType: 'full_day' | 'half_day' | 'leave' }`
  - Response: `{ message, attendanceType, standardHours }`

- **POST** `/api/manager/activities`
  - Request: `{ title, description, assignedToId, priority, status }`
  - Response: `{ message, activity }`

### Modified Endpoints:
- **GET** `/api/workday/status`
  - Now returns: `{ attendanceType, standardHours, clockedIn, clockInTime, clockOutTime }`

## Standard Hours Configuration

- **Full Day:** 9 hours (540 minutes)
- **Half Day:** 4.5 hours (270 minutes)
- **Leave:** 0 hours (0 minutes)

## Productivity Calculation

### Formula:
```
standardMinutes = standardHours * 60
productivity = (timeSpentOnActivities / standardMinutes) * 100

Examples:
- Full Day (9h): productivity = (timeSpent / 540) * 100
- Half Day (4.5h): productivity = (timeSpent / 270) * 100
- Leave (0h): productivity = 0% (no activities allowed)
```

## User Guide

### For Employees:
1. Login to Employee Dashboard
2. See "Mark Attendance" card
3. Select attendance type:
   - **Full Day (9 hours)** - Normal working day
   - **Half Day (4.5 hours)** - Half day work
   - **Leave (0 hours)** - On leave, no activities
4. Add activities as usual
5. Productivity calculated based on selected hours

### For Managers:
1. Login to Manager Dashboard
2. Go to "Team Members" tab
3. Click "Add Activity" button (top right)
4. Fill in activity details:
   - Title (required)
   - Description (optional)
   - Assign to employee (required)
   - Priority (low/medium/high)
   - Status (pending/in_progress/completed)
5. Click "Create Activity"
6. Activity appears in employee's dashboard
